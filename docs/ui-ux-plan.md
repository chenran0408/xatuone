# 一校通 UI/UX 与信息架构

## 当前结构：2026-11-07 信息架构重设计

本节取代下方历史轮次中的四项导航和混合服务目录。只调整入口、页面结构和展示；继续使用原 Repository、ViewModel、课程配置、账号状态与 WebView 会话。

```text
首页
├── 账号状态、日期与教学周摘要 → 账号管理
├── 正在上课／下一节课 → 今日安排；设置日期／同步课表
├── 宿舍电量与真实查询趋势 → 电费详情；未绑定时提供入口
├── 最近考试摘要 → 考试安排
├── 常用操作：成绩、签到、本周课程、校园服务
└── 教务异常、重新登录／重试与网络说明

├── 周课表 → 周次选择、切换课表、课程详情
├── 今日 → 今日安排
├── 同步课表 → XATU 适配器 → 选择导入学期
└── 课表设置
    ├── 日期、周次与显示（开学日期、总周数、周末、每周起始日、非本周课程）
    ├── 课程外观与颜色（既有布局、文字、网格、背景和颜色）
    ├── 节次与作息
    ├── 假期与调休
    ├── 管理课表、课程管理、批量调整课程
    └── 课表文件与系统日历
教务
├── 成绩查询（成绩、学分、绩点）
├── 考试安排
├── 学业进度（含培养方案）
├── 教学周 → 按需设置当前课表日期
├── 校历（日期、原图、识别文字）
└── 教务系统网页

```

### 导航与归属

- 手机底部五项等宽文字导航：**首页／课程／教务／校园／我的**；宽屏沿用侧栏。三风格共用同一目的地和业务状态。
- 首页顺序：账号／日期／教学周、今日课程与同步操作、宿舍电量及真实趋势、最近考试、常用操作、教务异常和网络说明。电量区域始终存在；未绑定和无记录有明确入口。首页首次创建按已绑定宿舍查询一次，手动刷新复用原 Service，保存到详情同一 Repository；失败保留旧记录并标注上次查询时间。
- 课程顶部保留同步入口；按后续首页重构要求，在首页课程摘要中加入同一适配流程的快捷操作，不复制导入逻辑。文件转换页中仅打开登录的旧“教务导入”入口仍已移除。
- 课表日期、作息、样式与管理工具从“我的”移到独立课表设置。全局主题和通知仍在“我的”。
- 校历从混合校园目录移到教务；签到网页与位置设置分别归入校园生活／服务设置，删除位置设置页内重复的网页入口。
- 账号管理为固定入口；未登录或会话过期时的登录按钮属于完成当前任务所需的上下文引导。
- 首页摘要的详情操作是上下文跳转，不复制成绩、电费或考试页面。教务和校园分别可搜索本组服务。

### 保留的业务边界

- 不新增课程模型或“学期”统一存储；本机课表、导入学期与教务查询学期继续使用各自现有状态。
- 课程显示设置仍遵循原有作用域：日期、作息等关联当前课表；应用级非本周课程显示偏好仍全局保存，没有迁移用户数据。
- 课程序号仍由脚本附在课程名称中；课程模块现可单独隐藏已识别的序号后缀，详情保留序号，原始名称不改写。
- 首页、详情、趋势及历史统一显示剩余电量“度”，数值沿用 `querySydl` 的现有解析，不更改数据或作单位换算。趋势仅连接真实查询记录，时间轴保留实际间隔；记录增加不宣称为用电量。
- 隐私与网络页提供真实说明和 Android 系统设置操作，没有新增虚构权限开关或会话清理操作。
- 未改 WebView、Cookie、API、账号清理、课程同步实现与存储格式；未新增未接入服务。

## 审计结论

- 本轮开始时，门户主要展示账号和服务目录，没有当前课程、教学周及最近考试摘要。
- 今日课表和周课表占用两个一级导航位置，缺少独立校园服务目录；服务详情曾依赖门户局部状态，难以保持清晰返回路径。
- “我的”首先展示课表配置，主题入口位于“更多”中；校园服务、课程配置和个人设置层级不清。
- 窄屏底栏隐藏文字；周课表隐藏底栏后，其他一级页可能继承隐藏状态。
- 三种风格已有共享组件和应用级偏好，继续保留同一业务状态和导航，不复制页面或更换依赖。

## 分轮实施

1. 一级导航统一为首页、课表、校园、我的。今日安排、课表日期与显示变为二级页面；新安装默认首页，保留已保存的今日/周课表启动偏好。
2. 首页按日期与教学周、当前/下一课、最近考试、常用服务、网络说明排序。课程读取既有 TodayScheduleViewModel；教务摘要读取现有账号和 AcademicRepository，显示账号隔离缓存、更新时间、刷新及失败状态。
3. 校园页集中教务学习、校园生活、更多网页服务，支持标题和说明搜索。网页服务明确标注；服务详情使用正式导航目的地，返回原入口，未登录及会话过期可直接登录。
4. 我的前置账号和界面主题，将课表日期配置收进独立页；更多页删除重复主题入口。主题保存提供保存中、成功、失败反馈。
5. 底栏等宽并保留文字及选中语义；宽屏使用侧栏。首页网格根据宽度和字体缩放调整列数；操作组可换行，滚动区预留底栏空间；离开周课表恢复导航可见状态。
