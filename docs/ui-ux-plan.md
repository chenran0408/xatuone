# 一校通 UI/UX 重构计划

## 审计结论

- Android 主导航已有校园门户、今日课表、周课表和设置四个一级入口，并具备自适应底栏/侧栏；暂不新增重复的主导航层级。
- XATU 门户把登录表单、常用功能和全部校园链接纵向堆叠，信息密度低，高频任务没有明确优先级。
- 成绩、考试、校历、学业进度等服务页混用 Material3、MIUIX 和硬编码颜色；学期选择按学期数量纵向展开。
- 电费、签到等状态页缺少一致的加载、保存、错误和空状态反馈。
- 通用课表、今日课表和设置已经使用应用级 Material 主题，应继续复用，避免再建第二套主题。

## 分轮实施

1. 门户与服务页：已完成。门户按学习、校园生活和更多服务分组；已登录账号默认紧凑显示并提供切换/退出；服务页改用应用级 Material3 主题、紧凑学期选择器、卡片内边距和明确加载/错误状态。
2. 导航与配置：已完成首轮。保留自适应一级导航；窄屏空间不足时切换为图标导航；增加屏幕阅读器 Tab 选中语义；非底栏布局统一落到侧栏；设置页教务入口标注门户主路径，副标题降级为辅助文字。
3. 移动体验与回归：源码与构建检查已完成。今日课表时间状态按分钟更新，跨午夜时日期和课程列表会刷新；管理网格按可用宽度自适应，课程实例页补有空状态和图标无障碍名称。Android 编译、host tests、Release lint、R8 Release 构建和 `git diff --check` 均通过。当前无连接设备，设备级截图、字号缩放、真实账号和校历/电费交互仍需实机验证。

## 验收标准

- 高频任务在门户首屏可见且直接进入对应流程。
- 每个门户入口与目的地名称一致；未实现功能不显示为可用入口。
- XATU 页面只使用应用级 Material3 主题和语义化颜色。
- 学期选择占用固定紧凑区域；加载、失败和空数据有明确反馈。
- 不删除课程表、账号、成绩、考试、学业进度、校历、电费、签到及校园网站现有能力。

## 本轮代码范围

- `XatuLoginScreen.android.kt`：XATU 门户信息架构、账号区和快捷服务入口。
- `XatuServicePage.android.kt`：服务页主题、卡片与状态反馈、学期选择。
- `NavigationComponents.kt`：自适应导航的窄屏布局和无障碍选中状态。
- `SettingsScreen.kt`：设置项信息层级和教务账号入口说明。
- `TodayScheduleScreen.kt`：今日课表课程状态随时间更新。
- `CourseInstanceListScreen.kt`、`CourseNameListScreen.kt`、`HolidayManagementScreen.kt`：自适应网格；课程实例空状态和操作无障碍名称。
